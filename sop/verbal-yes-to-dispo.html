✅ Verbal Yes → Contract → Dispo

🏠

① TL;DR

The agent or seller has said yes. You now have ~30 days to close. This SOP is the exact sequence from verbal yes to dispo'd buyer.

② When to use

  • Agent calls/texts: 'Seller agreed to your terms'
  • You have all four key numbers: price, down, balloon, closing date

③ How to run this play (step-by-step)

  1. Generate contract parameters
    In Claude Code on Mac: verbal yes on [address]. Returns the full BBC data entry block + addendum language + buyer dispo summary.
  2. Enter in BBC → Create Offer
    Open BBC Inventory → Create Offer. Fill the data block from Claude's output. Save the offer.
    BBC Inventory ↗
  3. Paste the addendum language
    Copy from Claude's output into the BBC contract template. Customize address, dates, amounts.
  4. Send to agent for execution
    BBC handles e-signature flow. Agent forwards to seller. Expect 24-72 hours for return.
  5. Start dispo immediately — don't wait
    The moment offer is sent, start marketing. Time matters.
  6. Generate buyer one-pager
    generate buyer one-pager for [address] — returns a public URL you can DM to out-of-network buyers (Instagram, FB, personal email).
  7. Submit to BBC Marketplace
    BBC Marketplace auto-dispos to BBC's curated buyer network.
    BBC Marketplace ↗
  8. Submit to Grand In Taylor LLC
    Creative form for seller finance / sub-to. Cash Alt form for cash deals.
    Grand In Taylor Creative ↗
  9. DM the buyer one-pager URL to known buyers
    Once Airtable Known Buyers exists, filter to buyers matching state + entry budget + deal type, then DM each.
  10. EMD timing — DO NOT submit early
    EMD ($1,000) submitted ONLY AFTER inspection period ends. Inspection is 10 biz days (min 7). Richard's company often covers EMD.
  11. Move BBC card to 'Under Contract' stage
    Track in BBC Inventory pipeline. Update status as inspection passes, EMD submitted, closing scheduled.
  12. Close in 30 days from execution
    Title transfer at closing. If Land Trust structure, Buyer named as beneficiary.
