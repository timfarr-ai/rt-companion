📅 Weekly Pipeline Review (Friday)

🏠

① TL;DR

End-of-week sweep. Catch verbal-yeses not yet under contract, review watchlist for price drops, refresh buyer criteria, plan next week's call list.

② When to use

  • Every Friday afternoon, ~2pm
  • Before logging off for the weekend

③ How to run this play (step-by-step)

  1. Review BBC Inventory pipeline
    Open BBC Inventory. For each card, confirm: status accurate? Inspection started? EMD timeline correct? Push verbal-yeses that haven't moved to under-contract.
    BBC Inventory ↗
  2. Check the rejected watchlist for price drops
    Tell Claude Code: check price drops — runs the Deal Monitor agent against the rejected-watch.md list. Newly qualified deals get added to next Monday's triage.
  3. Review past week's call log
    Open your Notes/Airtable call log. For every call from this week, mark: replied / no-response / dead. Move dead ones to watchlist.
  4. Refresh Known Buyers list
    Open Airtable Known Buyers (when set up). For each active buyer, confirm: state, entry budget, deal type, last contact. Re-engage anyone silent >30 days.
  5. Plan next week's call list
    Look at Monday's expected triage tier distribution. Schedule 2-3 call blocks across Tue/Wed/Thu. Pre-allocate 1 block per tier.
  6. Update Airtable + close out the week
    Any deals not actively in pipeline: archive. Any open questions for Richard/HMHW community: queue for Monday's HMHW livestream Q&A.
