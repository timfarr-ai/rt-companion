✉️ Agent Replied — Counter Analysis

🏠

① TL;DR

When an agent texts, emails, or calls back with new terms, route the message through Claude Code to get an instant counter analysis and response script. Don't reply blind.

② When to use

  • Agent texts/emails you with seller's counter terms
  • Agent leaves a voicemail with a partial counter
  • You need to know if the counter still pencils before responding

③ How to run this play (step-by-step)

  1. Capture the agent's exact words
    Copy the text/email verbatim. For voicemail, type out what they said.
  2. In Claude Code on Mac OR claude.ai iOS app — paste:
    agent replied: [paste their message] — Claude pulls the deal from context (or asks for the address), reparses the proposed terms, and runs the math.
  3. Review Claude's analysis
    You'll see: revised CF, revised CoC, whether deal still qualifies, recommendation (PROCEED / COUNTER BACK / KILL), and a response script.
  4. Apply Tier-specific rules before agreeing
    Tier A: NEVER exceed 10% down. Never give both premium AND interest. Push back firmly on these even if Claude approves CF-wise.
    Tier B: 12-14% down is OK. Interest at 4-6.5% is OK if price drops to asking.
  5. Send response
    Copy Claude's response script. Customize 1-2 phrases to sound human. Send via the same channel the agent used (text → text, email → email).
  6. Log the round
    Save the agent's message + your response in Notes/Airtable so you can reconstruct the negotiation history.
  7. If COUNTER BACK — schedule follow-up
    Most counters take 24-48 hours to resolve. Set a calendar reminder for 48h to check status.
